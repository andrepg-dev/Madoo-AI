# Madoo Design System

Bienvenido al sistema de diseño de **Madoo AI**. Este paquete (`@madoo/ui`)
expone los componentes, tokens y patrones de UI compartidos entre todas las
aplicaciones del monorepo.

## Filosofía

- **Landing-first**: el sistema nace desde la nueva landing. Blanco limpio como
  superficie principal, gris frio como campo, reglas azules finas y tinta casi
  negra.
- **AI email workflow**: cada componente debe servir para crear, editar,
  previsualizar y exportar templates. Evitamos UI generica que no muestre el
  producto real.
- **Tipografia nueva**: Figtree para titulares de marketing, IBM Plex Sans para
  UI, Inter como fallback de producto y JetBrains Mono para metadatos tecnicos.
- **Token-first**: cada color, radio o sombra esta en `tokens.css`. Los
  componentes nunca usan literales — siempre `var(--ink)` etc.
- **Shadow-border only**: cualquier borde visual se pinta con tokens
  `--shadow-border*`; no usamos `border` CSS para edges, dividers o estados.
- **Themed**: soporta tres temas (`default`, `paper`, `midnight`) intercambiables
  via `data-theme` en `<html>` o cualquier ancestro.

## Como usar

Instala el workspace package en cualquier app del monorepo:

```jsonc
// apps/<app>/package.json
{
  "dependencies": {
    "@madoo/ui": "workspace:*"
  }
}
```

Luego importa los tokens una vez (idealmente en el root layout) y usa los
componentes:

```tsx
import "@madoo/ui/tokens.css";
import { Button, Input, Modal } from "@madoo/ui";

export function Example() {
  return (
    <Button variant="primary" size="lg">
      Generate email
    </Button>
  );
}
```

## Estructura del paquete

```
packages/ui/
├── src/
│   ├── tokens/        ← tokens.css, fonts.css, base.css
│   ├── components/    ← un folder por componente con CSS + stories
│   └── lib/cx.ts      ← util de className merge
└── .storybook/        ← config de Storybook
```

## Mapa de componentes

| Categoría     | Componentes                                                       |
| ------------- | ----------------------------------------------------------------- |
| Acción        | `Button`, `IconButton`, `SuggestionChip`, `PromptPill`, `Kbd`     |
| Forms         | `Input`, `Textarea`, `Select`, `Checkbox`                         |
| Layout        | `Card`, `SelectableCard`, `Modal`, `SegmentedControl`             |
| Feedback      | `Banner`, `Badge`, `Tag`, `Spinner`, `ProgressBar`                |
| Identidad     | `Avatar`, `Icon`                                                  |

> El objetivo es que `@madoo/frontend` y `@madoo/landing` migren a un mismo
> lenguaje visual: paleta landing, helper compartido `.madoo-paper-border`
> y componentes UI listos para la nueva plataforma.
